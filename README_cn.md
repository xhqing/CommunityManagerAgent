# SocialMediaManagerAgent

> 🥂 **Gatsby** —— 社媒运营官。名字取自《了不起的盖茨比》的主人公 Jay Gatsby：文学史上最著名的派对主人。好的内容矩阵和好的派对一样，是被「设计」出来的——合适的温度、节奏，和对的人聚在同一个房间。Gatsby 负责运营群主本人的社媒账号矩阵：YouTube、小红书、公众号、小绿书、视频号、微信社群、朋友圈——理念和方法由智能体出，群主引导并在各平台落地执行。

[English](README.md)

SocialMediaManagerAgent 负责运营群主本人的社媒账号矩阵——以微信社群「AI+X 实战经验交流群」为私域核心，覆盖 YouTube、小红书、公众号、小绿书、视频号与朋友圈。日常工作：各平台内容策划、节奏与分发，社群定位与群规迭代、新人欢迎流程、话题日历、内容整理、运营复盘。群主全程在场，做引导与执行——发出去的每一条内容都经群主之手。

---

## Gatsby 是谁？

本 agent 拟人名为 **Gatsby**——取自 F. Scott Fitzgerald 笔下的传奇派对主人 Jay Gatsby。盖茨比办的派对让陌生人变成伙伴；这个 agent 运营的社群，把各行各业用 AI 的人聚在一起。

- **理念出智能体，执行出群主**。Gatsby 产出的一切都「拿来即用」：群公告、欢迎语、话题引导、平台内容，群主复制粘贴就能发。
- **宽松治理**。不涉违法违规敏感话题则言论不作限制；群规只在真问题出现后迭代——不提前立法。
- **活跃是唯一目标**。话题围绕「AI 结合各行各业怎么用」——不往纯技术群收窄，也不放任变成闲聊群。

## 运营矩阵

以微信社群为私域核心的 7 平台矩阵，内容策略是「一鱼多吃」——一次生产核心素材，按平台特性分发：

| 阵地 | 定位 |
|---|---|
| YouTube | 长期资产主阵地——深度长视频 + Shorts 切片 |
| 小红书 | 搜索长尾第二阵地——图文攻略 + 竖屏视频 |
| 公众号 | 深度内容基地 + 搜索资产 |
| 小绿书 | 流量入口与选题测试——轻内容图文 |
| 视频号 | 社交裂变与私域导流——竖屏短视频 |
| 微信社群 | 私域承接核心（信任场） |
| 朋友圈 | 私域日常触达与互动 |

## 这个社群

定位源自群主亲笔的群公告（2026）：

- AI 已渗透各行各业，不管你在哪一行，AI 都能帮上忙——问题只是怎么把它用起来。
- 以 AI 为纽带，主打 **AI 实战经验交流**（「AI+X」：AI 结合各位所在的行业，怎么用、用出什么效果、踩过哪些坑；新的模型和工具也会第一时间分享，但重点始终是把它用起来）。
- 群主的 AI 智能体团队全部开源在 [github.com/xhqing](https://github.com/xhqing/)，欢迎群友随时参观。

## 三层公平治理（社群特色）

本群的公平治理理念分三层，对全体群友公开，欢迎监督：

| 层 | 载体 | 作用 | 状态 |
|---|---|---|---|
| 运营层 | 群规修订程序（提前 7 天公示） | 白纸黑字的程序承诺——群主也不能说改就改 | ✅ 已落地 |
| 记录层 | GitHub 公开仓库 + Release 发版 | 每次修订有公开时间戳的版本历史，点链接即可查证 | ✅ 已落地 |
| 承诺层 | 区块链存证（修订记录写入后不可修改、任何人可查证） | 「群主想改也得等公示期满」的硬承诺 | 📋 公开备选 |

承诺层暂不实施、方案公开（[commitment-layer.md](docs/community/commitment-layer.md)）——它既是社群特色，也是一个群友知晓的备选项：**如果有很多群友明确要求用上这一层，呼声够多就启动**。

## 在团队中的位置

| Agent | 角色 |
|---|---|
| **Gatsby**（本项目） | 社媒运营——群主账号矩阵的内容、节奏、复盘 |
| Kit（ExecutiveAssistantAgent） | 总经理助理——找单接活与综合事务 |

Gatsby **直属用户**，在团队三个小组之外——社媒矩阵是用户自己的阵地，不是销售流水线的资产。（为数字产品销售做渠道引流内容归数字产品销售小组的 Buzz；Gatsby 负责群主本人账号的长期运营与私域阵地——平台有重叠，任务不同。）
