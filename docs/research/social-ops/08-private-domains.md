# 素材 08：私域阵地（微信社群 + 个人朋友圈）

> 用途：低频深度参考 → skill references。
> 说明：**微信社群的运营体系 Gatsby 已有成熟积累（项目 CLAUDE.md），本文件不重复**，只写「社群与朋友圈在社媒矩阵中的位置与协同」；**朋友圈本会话未做专门调研（无公开算法可查），以下为框架性内容 + 如实标注**。

## 一、社群在矩阵中的位置（已有体系的定位说明）

- **社群 = 私域承接核心（信任场）**：所有公域平台（YouTube/小红书/公众号/小绿书/视频号）的流量最终都往这里承接——「不拆地基：群是信任场不是卖场」；
- **与公域的区别**：
  - 公域内容（公众号文章/视频）是「一次性分发 + 算法放大」；
  - 社群是「关系触达 + 信任沉淀」——与更新节奏解耦的资产（停更公域内容，群还在）；
- **社群的独特杠杆（在社媒矩阵中的新作用）**：
  1. **视频号冷启动的社交资产**：群友点赞/转发是视频号社交推荐（朋友点赞推荐）的启动引擎；
  2. **内容测试场**：新内容先发群内看反馈，再决定是否投入制作分发；
  3. **公域内容的选题来源**：群聊里高频出现的问题 = 公域内容（小红书/YouTube）的选题库。

## 二、朋友圈（框架性内容，未专门调研）

**已知基础**：
- 朋友圈是**纯私域触达**：发布可见性由好友关系决定（无算法分发），是「个人化、生活化」的触达场；
- 与公众号/视频号的联动：朋友圈可转发公众号文章、视频号内容（生态内一键分享）；
- 触达形态：短图文、转发分享、带评论转发。

**基于已知原理的操作框架（待实践验证）**：
1. **定位**：温度与信任的日常维护——不承担「内容分发」任务（那是公域平台的事），承担「人味与关系」；
2. **内容类型**：公域内容的「幕后花絮」、个人日常、观点碎片、互动话题（提问/投票）；
3. **频率**：自然频率（每日 1-3 条），避免刷屏与营销感；
4. **与社群配合**：重要公告/活动 → 朋友圈预告 + 社群落地；
5. **注意**：朋友圈不是内容资产的载体（不可搜索、无推荐分发）——不要把它当公域发。

**待补充（Gatsby 实践中沉淀）**：
- 朋友圈的内容类型与效果复盘；
- 朋友圈与社群的节奏配合（发什么、什么时候发）；
- 带评论转发的话术与打开率优化。

## 三、私域协同的总原则

```
公域平台（YouTube / 小红书 / 公众号 / 小绿书 / 视频号）
    ↓ 导流承接（平台允许的方式：菜单栏 / 关注自动回复 / 站内功能 / 视频号直连）
社群（信任场：AI+X 实战经验交流群）
    ↓
朋友圈（日常温度与关系维护）
```

**操作纪律**：
1. **导流靠合规通道**（红线见 02）——公域内容里不放联系方式；承接走：
   - 视频号 → 微信生态（天然直连，最顺滑）；
   - 公众号菜单栏 / 关注自动回复；
   - 平台内「查看全文」等站内跳转；
2. **社群是终点站**：所有平台内容都设计一个「到社群的路径」（如文章末尾引导、视频评论区引导——**注意各平台导流规则的差异**）；
3. **停更保护**：私域（社群+朋友圈）是与公域更新节奏解耦的资产——公域停更期间，私域仍可维持关系与触达。
