## 四、素材的时效与可靠性标注

每份文档中的数据都标注了来源与时间（会话调研日期 2026-10-14）。请注意：

- **官方来源**（平台官方文档 / 官方公告 / 官方账号）→ 可放心使用；
- **第三方分析**（行业媒体、数据服务商、运营号）→ 标注了「第三方」，使用时应保留「非官方、可能变化」的认知；
