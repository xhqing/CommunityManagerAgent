# 素材 01：社媒矩阵总览（7 个产品）

> 用途：平台矩阵是每次运营决策的起点——建议提炼进 CLAUDE.md（高频）。
> 数据时效：2026-10-14 调研，第三方数据已标注。

## 一、矩阵全景表

| 产品 | 形态 | 在矩阵中的角色 | 内容定位 | 建议节奏 |
|---|---|---|---|---|
| **YouTube** | 横屏长视频 + 竖屏中短视频（Shorts） | **长期资产主阵地**（搜索长尾 + 直接变现） | 深度内容：系统讲解、教程、分析 | 长视频每 1-2 周 1 条；Shorts 切片可高频 |

## 二、内容策略：一鱼多吃

一次生产的核心素材，按平台特性分发（降本的核心逻辑）：

```
【核心选题】
   ↓
① YouTube 长视频（深度版，3-10 分钟）
   ↓ 切片
② YouTube Shorts / 视频号 / 小红书视频（1-3 分钟精华版）
   ↓ 改写
③ 公众号文章（深度文字版——可先写文再拍视频，也可视频转文字稿）
   ↓ 摘取
④ 小绿书贴图（要点清单版）/ 小红书图文笔记（攻略版）
   ↓ 导流承接
⑤ 微信社群 + 朋友圈（预告、摘要、互动）
```

要点：
- **「可搜索化」是通用改造方向**：每篇内容当「搜索题的答案」来写——标题/首段/标签布入目标用户会搜的词（YouTube 靠字幕+标题+描述；小红书靠关键词；公众号靠标题+正文；小绿书靠图+文案）；
- **脱敏与合规改编**：涉及敏感话题（交易/金融）的内容，分发到国内平台时要按红线降级处理（见 02 红线速查）。

## 三、平台分层：投入优先级

按群主目标（挣钱 + 复利 + 影响力 + 导流）排序：

1. **第一梯队（资产型，优先投入）**：
   - **YouTube**：复利最强（内容吃数年）、变现机制最实（广告分成）、搜索长尾；
   - **公众号**：搜索长尾（微信搜索 42% 流量流向公众号）+ 流量主变现 + 深度承载；
2. **第二梯队（流量型，配合分发）**：
   - **小红书**：搜索长尾好（但导流受限、变现靠商单）；适合攻略/工具类内容；
   - **视频号**：社交裂变（朋友点赞传播）+ 私域直连；适合短视频分发；
3. **第三梯队（测试与承接）**：
   - **小绿书**：官方扶持期红利（信息流每 2-3 屏推荐）、0 粉可测；做轻内容与选题测试；
   - **微信社群**：私域信任场（承接所有平台流量）；
   - **朋友圈**：日常触达与温度。

## 四、平台的关键机制差异（速记版）

| 维度 | 关键结论 |
|---|---|
| **搜索长尾** | YouTube ≈ 小红书 > 公众号 > 视频号 > 抖音（微信搜索内：公众号 42% > 视频号 27%） |
| **分发逻辑** | YouTube/公众号/小红书=搜索+推荐混合；视频号=社交推荐为主；小绿书=纯推荐；社群/朋友圈=关系触达 |
| **爆款难易** | 小绿书、小红书（0 粉可起）> 视频号 > 公众号/YouTube（需积累） |
| **变现** | YouTube（AdSense，门槛 2027-02 起翻倍）、公众号/小绿书（流量主）、视频号（创作分成）> 小红书（商单为主） |
| **导流** | 社群/朋友圈（自有）；视频号→微信生态（顺滑）> 小红书（受限）> 公众号（导流影响推荐）> YouTube（描述链接可行） |

## 五、与其它 agent 的协作边界

- **Buzz（GrowthMarketerAgent）**：负责「数字产品销售」的**渠道引流内容**（X / IG / YouTube / 小红书 / 知乎 / B 站）——为产品卖货服务；
- **Gatsby（本 agent）**：负责**群主本人的社媒矩阵运营**（内容资产建设 + 私域阵地）——为个人品牌与长期资产服务；
- 两者平台有重叠（YouTube / 小红书），但任务目标不同：Buzz 是「一次性的引流动作」，Gatsby 是「长期账号运营」。**运营群主本人的账号 = Gatsby 职责；为某个产品销售做引流素材 = Buzz 职责。** 遇到边界模糊的场景，与 Buzz 协商确认。
