# 素材 02：合规红线速查（导流 / AI 内容 / 金融内容）

> 用途：**每次创作与发布内容前都要对照的最高优先级检查清单**——建议完整提炼进 CLAUDE.md（高频）。
> 时效：2026-10-14 调研；平台规则变化频繁，执行前建议复查最新版本。

## 红线一：导流（把用户往站外/私域引导）

**统一原则**：2025-2026 年各平台集体收紧导流——「在内容里放联系方式」从「灰色」变成了「明牌禁区」。

| 平台 | 规则要点 | 后果 |
|---|---|---|
| **小红书** | 笔记、评论、个人资料、私信中留或暗示微信 / QQ / 二维码均属违规导流 | 限制账号功能 |
| **公众号** | 2026-05 起：文章含导流内容（个人微信/二维码/站外链接）→ 被标记「不符合内容推荐条件」 | **不封号，但该文章失去推荐流量**；账号检测可查（公众号助手 App） |
| **抖音** | 禁止站外导流、诱导站外交易 | 限流/处罚 |
| **雪球** | 昵称/简介/头像/内容中附加站外联系方式（电话/二维码/链接）禁止 | 删帖/禁言/封号 |
| **视频号** | 金融公约含「视频引流」黑名单；一般导流同样受限 | 限流 |
| **YouTube** | 相对宽松，描述区可放链接（注意：以站外导流做金融变现仍有法律风险） | — |

**操作纪律**：
1. 国内平台内容一律**不放联系方式**（微信号、二维码、电话、外部群）；
2. 私域承接走**平台允许的功能**（公众号菜单栏、关注自动回复等）+ **站内功能**（如小绿书「查看全文」跳长文）；
3. 出现「不良信息」标记时按 `04-xiaohongshu.md` / `05-wechat-mp.md` 中的处理流程操作（**不要批量删文**）。

## 红线二：AI 内容（生成方式与标注义务）

**法律层面**（中国《人工智能生成合成内容标识办法》，2025-09-01 施行）：
- AI 生成/合成的文本、图片、音频、视频**必须标识**；
- 视频：起始画面 + 播放周边显著位置加提示（文字高度 ≥ 画面最短边 5%，显示至少 2 秒）；
- 发布者义务：主动声明 + 使用平台标识功能；**禁止去标**；
- 后果：行政处罚、民事赔偿、严重者刑责。

**平台层面（2026 年新规）**：

| 平台 | 规则 | 判定逻辑（关键） |
|---|---|---|
| **公众号** | 2026-03-27「非真人自动化创作行为」：禁止 AI/脚本/接口替代真人完成创作与发布；禁止批量自动化发布；禁止传播该类教程 | **判定看「文本特征 + 创作参与度」**——「算法抓的不是你有没有用 AI，是你的内容长得像不像 AI 写的」；已有批量删文案例 |
| **视频号** | 2026-04 起：AI 生成/辅助内容必须标注「AI 技术生成」 | 未标注 → 限流/下架 |
| **小红书** | AI 内容需标注；平台打击低质 AI 铺量、「AI 味浓」内容难起量 | 真实度评估 |
| **YouTube** | 需披露（altered content）；**批量生产、重复无增量的 AI 内容不予变现**（2025-07 inauthentic content 政策）；**AI 生成的金融建议内容不可变现**（2026） | 原创脚本/观点/编排 + AI 辅助 = 合规 |

**操作纪律**：
1. **AI 做辅助、人做核心**——选题、观点、框架、个人经历由真人提供；AI 用于资料整理、润色、排版、配图、剪辑；
2. 每条 AI 参与的图文/视频**发布时勾选 AI 标注**（各平台内置功能）；
3. 避免「批量生产 + 模板化」——正文里注入个人观点、真实经历、一手数据，保持表达的个人风格；
4. 不做「纯 AI 代写」——即使人工审阅，「让 AI 改几版」不改变文本的 AI 特征，仍属高风险。

**特别提醒（当前的自己人话版）**：判定标准是「内容活不活得像 AI」，不是「你用没用 AI 工具」。一份「AI 代写 + 人工验收」的文章，风险等级高于「真人主笔 + AI 润色」的文章——差距就在于**文章里有没有注入只有真人能提供的东西**（观点、经历、数据、风格）。

## 红线三：金融 / 交易内容（法律 + 平台双重监管）

**法律层面**（这是所有红线里唯一可能涉及刑责的）：
- 未取得证券投资咨询资质，提供**具体投资建议**（推荐标的、预测股价、指点买卖时机）→ 可能构成**非法经营罪**；
- 无论是否收费，只要提供具体建议并引导交易，都可能涉嫌非法经营；
- 案例：雪球大 V 金某操纵证券市场 → 罚没 8325 万元 + 3 年市场禁入（2026-01）；抖音单季处置财经违规内容 4.5 万条。

**官方边界口径**（抖音副总裁李亮，2025-12，可作为通用参照）：
> 「重点打击**不具备专业资质讲解金融市场等专业性内容、推荐金融产品**的现象。**大家日常分享客观、合规的财经类经验是完全 OK 的。**」

**平台规则（2025-2026 收紧潮）**：

| 平台 | 要点 |
|---|---|
| **抖音** | 2025-12《财经行业公约》：未认证账号不得发布「专业财经内容」；禁非法荐股、承诺收益、诱导站外交易 |
| **视频号** | 2026-03《金融行业公约》（4-1 生效）：8 类黑名单——公开荐股、承诺收益、恶意唱衰、违规服务、伪造背书、低质同质化、NFT 等、视频引流；资质认证（人证一致） |
| **小红书** | 非认证账号**禁用「证券」「基金」等金融属性字眼**（容错空间最小） |
| **公众号** | 金融类内容规范；无资质不得金融营销 |
| **YouTube** | 相对宽松（无资质门槛）；但 AI 金融建议不可变现；不承诺收益；**法律风险不因平台在境外而消失**（面向中国投资者 + 收费提供建议仍有风险） |

**内容分级（对照发布）**：

| 内容类型 | 风险 | 说明 |
|---|---|---|
| 系统/技术/工程类（架构、数据、编程、工具） | ✅ 低 | 讲技术不讲建议——最安全的切口 |
| 知识/科普类（术语、机制、软件教程） | ✅ 低 | 不落具体标的 |
| 方法论/风控类（一般原则） | ⚠️ 中 | 一具体到「什么时候买什么」即危险 |
| 实盘/记录/业绩类 | ⚠️ 高 | 可能被认定变相荐股（带标的+买卖点+引导跟单） |
| 荐股/诊股/买卖点/收益承诺/代客理财 | ❌ 红线 | 法律风险（非法经营罪等） |

**操作纪律**：
1. 涉及交易/金融的内容，**只做「技术与知识」方向**（系统怎么搭、工具怎么用、机制是什么）；
2. 实盘/记录类：定性为个人记录、不加跟单引导、不承诺/暗示收益、脱敏处理（但脱敏+免责声明≠绝对安全）；
3. 国内平台从严（公平起见：无资质先做技术/科普；敏感话题留待资质或与持牌机构合作）；
4. 免责声明（「不构成投资建议」）必要但不充分——有它比没有好，它不能把违规变合规。

## 发布前检查清单（每条内容发布前过一遍）

- [ ] **无导流**：正文/标题/评论/图片中无微信号、二维码、外部链接、联系方式（国内平台一律不放）；
- [ ] **AI 标注**：AI 参与制作的内容已勾选平台标注功能（图文/视频）；
- [ ] **金融合规**：涉交易/金融内容 → 无具体标的推荐、无买卖点、无收益承诺、无跟单引导；只讲技术/知识/一般方法；
- [ ] **搜索化**：标题/首段/标签已布入目标用户会搜的词；
- [ ] **平台适配**：内容形态符合目标平台规范（尺寸/时长/字数/格式——见各平台参考文件）；
- [ ] **无违规词**：过一遍平台敏感词（尤其金融类：小红书连「证券」「基金」字样都受限）；
- [ ] **版权合规**：图片/音乐/素材来源合法（封面用原创或授权素材）。
