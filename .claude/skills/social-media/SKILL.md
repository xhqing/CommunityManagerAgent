## 标准工作流（每条内容）

1. **选题**：优先搜索长尾型 / 常青选题（教程、攻略、决策类——每个选题当「搜索题的答案」来做）；社群高频问题 = 选题库（见 `references/private-domains.md`）；涉交易 / 金融的选题先按红线三分级（技术知识 ✅ / 实盘记录 ⚠️ / 荐股买卖点 ❌）。
2. **生产**：一鱼多吃（核心素材 → 多形态分发，路径见 `CLAUDE.md`「你运营的社媒矩阵」节）；**AI 做辅助、人做核心**——选题、观点、框架、个人经历由真人提供，AI 只做资料整理、润色、排版、配图、剪辑。
3. **发布前**：逐条对照 `CLAUDE.md`「合规红线与发布前检查」（三大红线 + 7 项检查清单）；再按目标平台查对应 reference 的平台专项限制（如小红书金融字样、视频号金融公约、各平台参数）。
4. **发布与承接**：发布动作由群主落地；可自动化的环节用执行 skill（公众号 → `wechat-mp`、剪辑 → `video-editing`、微信客户端 → `wechat-mac-ops`）；私域承接路径设计见 `references/private-domains.md`（走平台允许的功能，不放联系方式）。
5. **复盘**：数据按各平台机制解读（小红书看发布后 1-3 小时数据窗口、公众号看完读率、YouTube 看观看时长）；被标记 / 限流按对应 reference 的「不良记录处理」流程走——**只处理问题条目、绝不批量删文**。

## 通用心法（先懂原理，再套平台）

- **内容资产 vs 流量租赁**：搜索型平台（YouTube / 小红书 / 公众号）= 停更后老内容仍产流量（资产）；推荐型（抖音 / 视频号等）= 停更即断供。优先常青内容 + 库存制生产。
- **推荐系统三段式**（召回 → 排序 → 重排）：各平台第一指标不同——公众号看完读率、YouTube 看观看时长、小红书点击率 → 完读率、视频号看社交互动。内容制作跟着第一指标走。
- **0 粉可爆 ≠ 结果平等**：内容级赛马（数据达标即被放大），粉丝只影响起跑加成；成熟账号系统性占优。
- **投流是放大器，不是救命药**：只给「自然表现好」的内容投流；救不活已凉的笔记。
- **真实稀缺是壁垒**：AI 供给爆炸后，「真人真事 + 个人观点 + 一手经验」反而最稀缺——这正是各平台官方口径反复强调的关键词（「真实表达」「个人观点」「真人真事」）。

## 时效纪律

- 各 reference 的调研时点为 **2026-10-14**（来源已逐份标注：官方 / 第三方）；平台规则变化频繁（2025-2026 各平台密集出新规）——**引用任何门槛数字、政策条款前先复查最新版本**（查官方文档 / 官方公告；第三方解读只作线索）。
- 素材原始快照存于 `docs/research/social-ops/`（历史存档，仅供溯源；**现行内容以本 skill 与 `CLAUDE.md` 为准**）。
