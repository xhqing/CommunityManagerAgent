# 微信公众号运营参考（内容规则）

> 来源：Kit 交接素材 05（2026-10-14 调研；官方公告 + 第三方分析已标注）。
> 分工说明：本文讲「内容怎么写、规则怎么守」；写进草稿箱的操作走 `wechat-mp` skill。
> 时效提醒：平台规则变化频繁，执行前复查最新版本。

## 一、平台参数（发布时对照）

| 项目 | 规则 |
|---|---|
| 形态 | 长图文（支持图片/视频/音频/表格） |
| 群发 | 每天 1 次（订阅号） |
| 字数 | 无硬性限制（实操建议 1500-3500 字，完读率友好） |
| 标题 | 64 字内（建议 20 字内移动端显示完整） |
| 已发布修改 | 支持修改正文文字、**删除/替换图片（3 张内）**、标题 3 字、摘要等；修改机会有限（以后台实际显示为准） |
| 删除 | 正常删除已发文章**不会因删除操作影响账号推荐**（官方 2026-07 微信公开课） |

## 二、推荐机制（现行）

**格局**：私人订阅 + 公域推荐混合——2025 年起个性化算法推荐全面铺开；第三方分析称非粉丝流量占比可达 70%-90%（其中推荐流量约 50-60%）。

**推荐入口**：订阅号消息列表（智能排序）+ **看一看**（社交推荐「朋友在看」+ 算法「精选」）+ 文章底部相关阅读 + 微信搜一搜。

**算法指标权重**（第三方分析，非官方）：**完读率（约 35%）> 分享/转发（约 30%）> 收藏率（约 20%）> 互动质量（约 15%）**——完读率是第一指标；点开后 30% 进度内关闭会被标记「低质/标题欺诈」。

**官方推荐偏好（微信公开课 2026-07，权威）**：一句话概括是「**有真心、有干货、有审美**」，具体五类：
1. 有深度、有观点的原创内容；
2. 读起来舒服的内容（排版清爽、图文搭配合理）；
3. 能让人「读着读着有点收获」的内容；
4. 专业人士的权威内容；
5. 真人真事的真实分享。

# 三、AI 内容新规（2026-03-27 生效，重要）

《微信公众平台运营规范》新增「**非真人自动化创作行为**」：
- **禁止**：利用 AI、脚本、接口替代真人完成内容创作、发布；通过脚本/程序托管**批量、连续发布**；传播「非真人自动化创作」的教程/方法/服务；
- **判定逻辑**（关键）：看「文本特征 + 创作参与度」——「算法抓的不是你有没有用 AI，是你的内容长得像不像 AI 写的」；**用人工写出「AI 风格」的模板化内容一样会被判定违规**；
- 高危特征：无信息增量的整合内容（无独家信源/观点）、模板化套路写作（固定的总分总+对仗标题+标准化开头结尾）、低权重账号的量产内容；
- **后果**：已有批量删文、账号封禁案例；原创权重下跌、推荐量腰斩；
- **合规路径**：AI 辅助（查错/润色/图表）可用；选题、观点、框架、个人经历由真人主导；每篇注入「只有你能提供的东西」（观点/经历/数据/风格）。

# 四、导流新规（2026-05 起，重要）

- 文章含导流内容（个人联系方式、二维码、外部链接等）→ 被标记「**不符合内容推荐条件**」→ **失去推荐流量**（不封号）；
- 检测工具：公众号助手 App「账号检测」（条件：累计发文活跃天数 ≥12）；
- 规则统一标准（几千万公众号一视同仁）；
- **操作纪律**：正文不放联系方式；承接走平台功能（菜单栏、关注自动回复等）。

# 五、不良记录处理流程（实用快查）

**场景**：账号检测发现「不良信息」标记（如曾发布带二维码的文章）。

**处理流程（不要批量删文——这是最大的误区）**：
1. **只处理问题文章**：优先**修改**（用「修改」功能删掉二维码图片/联系方式），其次删除单篇；
2. **不要批量删文**：系统依据「历史发文质量 + 账号整体权重」判断，批量删文会造成「内容不连贯、活跃度异常」，反而更糟（有案例删 5 篇后连基础展现都没了）；
3. **连续输出高质量内容对冲**（系统评估周期约 15 天）：每篇至少 3 个独特观点/可操作方法、标题平实、配图原创；发文频率稳定（每天 1 篇或隔天 1 篇）；
4. **申诉**（在持续输出后再做）：公众号助手 → 账号检测 → 底部「问题反馈」→「单篇内容流量反馈」→ 勾选文章 + 说明已整改；等待 1-3 个工作日；不要重复提交；
5. **恢复后**：系统持续监测，再犯处罚更重。

# 六、变现机制

**流量主**：
- 开通门槛：2026 年初从 500 粉下调至 **100 粉**（第三方数据，以后台为准）；
- 收益公式：广告展示 × eCPM ÷ 1000；
- **eCPM 按赛道差异巨大**（第三方数据）：财经/教育/母婴/职场等 8-15 元/千次阅读（eCPM 20-60 元）；泛娱乐/鸡汤 1-3 元/千次——**垂直专业内容单价远高于泛娱乐**；
- 广告分成按阅读量结算，内容持续产生阅读 = 持续收益（与更新节奏解耦的长尾变现）。

**其它**：赞赏（读者打赏）、付费功能、品牌合作、带货（微信小店）。

# 七、搜索长尾（微信生态内）

- **微信公众号是微信搜索流量的最大受益者**：微信搜一搜日均搜索超 10 亿次，其中 **42% 流量流向公众号内容**（第三方分析）；
- 文章是「搜索资产」——每篇是独立搜索答案，生命周期可达数月至数年（优质旧文推荐周期从 24 小时延长至 7 天甚至数月）；
- **搜索化写法**：标题含核心关键词；正文自然融入目标用户会搜的词（不堆砌——微信也有语义理解）。

# 八、草稿箱 API（关联现有 skill）

- `draft/add` 接口：官方支持第三方调用（权限集 id 11、100）；需要已认证公众号 + 开发者模式 + IP 白名单；
- **边界**：接口使用合规（生态内第三方编辑器均如此）；真正的风险在「内容来源」——**AI 代写主体内容 + 脚本批量推送/发布 = 违规链路**；「真人写好 → 脚本推送草稿 → 人工确认发布」= 合规；
- 现有 `wechat-mp` skill 覆盖「Markdown → 草稿箱」的全流程（公式转图、图床上传、封面、预览），直接复用。

# 九、运营要点（来自本会话）

- **内容定位**：深度文章（官方偏好第 1/4 类）+ 搜索长尾型内容；
- **排版**：清爽（官方偏好第 2 类——文字密度、图文搭配）；
- **推荐适配**：完读率优先——开头 3 段抓注意力、段落短、信息密度高；
- **更新节奏**：每周 1-2 篇 + 批量库存制（严防断更超 3 天）；
- **数据自测**（第三方经验）：近 10 篇去掉选题只看行文结构，若「段落长度/句式/开头结尾高度趋同」→ 模板化特征明显，触发 AI 判定概率高。
