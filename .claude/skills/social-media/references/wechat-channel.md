# 视频号运营参考

> 来源：Kit 交接素材 07（2026-10-14 调研；官方公告 + 第三方分析已标注；多数运营数据为第三方，官方口径较少）。
> 时效提醒：平台规则变化频繁，执行前复查最新版本。

## 一、平台参数（发布时对照）

| 项目 | 规则 |
|---|---|
| 形态 | 竖屏中短视频（1-30 分钟，主流 1-3 分钟） |
| 入口 | 微信内嵌（发现页/朋友圈/公众号/搜一搜多渠道） |
| 内容形式 | 视频 + 直播 |
| 与公众号打通 | 主页展示视频号动态；手机端创作入口合并 |
| AI 标注 | 2026-04 起：AI 生成/辅助内容必须标注「AI 技术生成」（未标注→限流/下架） |

## 二、推荐机制（社交 + 算法双引擎）

**核心特点：社交推荐为主**（微信官方 2025-04 确认「视频号主要依靠社交好友关系进行推荐」）：
- **朋友点赞传播**：你点赞的视频会被推荐给你的微信好友（微信隐私保护指引明确）；
- 早期数据（2022 曝光）：「朋友点赞的社交推荐占比 55%、热门推荐只占 15%」（比例可能变化，方向仍成立）；
- 曝光四层构成：关注流量 + 好友关系流量（朋友点赞触发二次传播）+ 算法推荐 + 搜索；
- **含义**：视频号的冷启动依赖社交资产——**有私域基础（好友/社群活跃）时起量更快**；纯新号无社交资产则起步慢。

**搜索流量**（后面会纠正的一个偏差点）：
- 视频号内容被微信搜一搜索引；**微信搜索流量中 27% 流向视频号内容**（第三方分析，公众号 42% 为第一大受益者）；
- 「视频号搜一搜 SEO」是成熟的运营领域：标题/文案/描述埋词（品牌词、品类词、场景词、疑问词）；
- **停更后**：社交流量断、搜索流量留存（被收录的视频可被持续搜到）——搜索长尾存在但非流量大头。

## 三、变现机制

- **创作分成计划**：基于广告展示的收益模式——在原创视频评论区、个人主页视频流展示广告；**门槛 2025 年底从 1000 粉下调至 100 粉**（第三方数据）；分成比例约 60%；
- 收益水平（第三方实测）：普通内容 0.3-1 元/千次播放；垂直优质内容（财经/法律/教育/职场）1.5-5 元/千次；
- 其它：直播打赏、带货（微信小店）、视频号橱窗。

## 四、内容红线（2026 年新规密集）

**金融行业公约**（2026-03 发布，2026-04-01 生效）：
- 资质要求：宣称「基金经理」「基金公司」「证券公司」等身份必须完成职业认证；已认证账号发布投资理财内容时**主要出镜人须为认证人**（人证一致）；
- 禁止资质出借/买卖/挂靠；
- **8 类内容黑名单**：公开荐股、承诺收益、恶意唱衰、违规服务、伪造背书、低质同质化内容、NFT 等高风险项目、视频引流。

**直播规范**（2023-12 起）：金融科普类直播须**真人出镜**、**不得展示 K 线**；账号须本人使用（禁止外借/出租/共享）。

**AI 内容**：2026-04 新规——AI 生成/辅助内容必须标注，否则限流下架。

## 五、运营要点（来自本会话）

- **矩阵定位**：短视频分发主通道之一（与 YouTube Shorts / 小红书视频同源）+ 私域导流入口（视频号 → 公众号 → 社群闭环）；
- **一鱼多吃**：把 YouTube 长视频切片成 1-3 分钟版本，或直接制作短视频内容，同步分发视频号/小红书/Shorts；
- **搜索化**：标题/文案布关键词（视频号 SEO）；
- **社交启动**：利用社群（自己的群友点赞传播）做冷启动——这是 Gatsby 的独特优势（社群就是视频号的社交资产）；
- **更新节奏**：与短视频生产同步（无需单独拍摄）；
- **合规**：AI 内容标注、金融内容（如涉及交易类素材）按 8 类黑名单严格回避。

## 六、与其它平台的配合

| 场景 | 操作 |
|---|---|
| 视频制作 | 用 `video-editing` skill（ffmpeg + ChatCut），按微信分享硬规格输出 |
| 公众号联动 | 视频号内容可在公众号文章中嵌入（生态内互通） |
| 社群导流 | 视频号内容 → 社群分享 → 群友转发 → 社交裂变 |
| 搜索沉淀 | 视频标题/描述埋词 → 被微信搜一收收录 → 长尾流量 |
