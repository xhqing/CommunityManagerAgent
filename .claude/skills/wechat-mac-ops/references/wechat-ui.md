# 微信 Mac 4.x 界面地图

坐标一律以**截图（`ocu.sh` 存下的 ocu-shot.png）**为基准。下面给的比例是「占截图宽/高的百分比」，窗口尺寸变了按比例换算；精确落点每次现量。

## 窗口清单

用 `wxgeom.py geom` 能看到微信的多个窗口，各自用途：

| 窗口名 | 是什么 | 备注 |
|---|---|---|
| `微信` | 主窗口（会话列表 + 聊天区；点「···」后右侧多出群信息面板） | 所有日常操作的入口 |
| `微信 (窗口)` | 独立聊天窗口 / 内置浏览器窗口（点聊天里的链接会开在这里） | 误开后关掉：它自己的红色关闭按钮 |
| `"群名"的群公告` | 群公告窗口（查看态 → 编辑态） | 任务 2 的主角 |
| 无标题小窗口 | 各类确认弹窗（改群名、发公告、未保存提示） | **坐标换算要单独算，见 computer-use.md** |
| `微信`（登录页形态） | 未登录时的启动页（「进入微信 / 切换账号 / 仅传输文件」） | 点「进入微信」即进入，无需扫码 |

```
│  │               │ 消息输入框                     │              │

```

关键控件的大致位置（比例，截图左上角为原点）：

| 控件 | 位置（占截图比例） | 识别特征 |
|---|---|---|
| 搜索框 | x ≈ 0.19，y ≈ 0.04 | 有「搜索」占位文字；⌘F 可聚焦（聚焦后外框变绿、右侧出现麦克风图标） |
| 会话列表首行 | x ≈ 0.23，y ≈ 0.13 | 每行含头像 + 标题 + 最后一条消息 |
| 群聊标题 | x ≈ 0.35–0.55，y ≈ 0.04 | 形如 `AI+X 实战经验交流群 (23)` |
| 「···」按钮 | x ≈ 0.945，y ≈ 0.04 | 标题行最右侧三个点；点开 = 右侧信息面板出现/收起 |
| 消息输入框 | x ≈ 0.55，y ≈ 0.82 | 空时显示「按住鼠标 语音输入文字」 |
| 发送按钮 | x ≈ 0.93，y ≈ 0.90 | 输入框聚焦且有内容时才出现（灰色 = 不可点） |
| 信息面板「群聊名称」行 | x ≈ 0.72–0.9，y ≈ 0.56–0.65 | 上行小字「群聊名称」，下行是当前群名 |
| 信息面板「群公告」行 | 紧接在群聊名称下方（y 约 +0.06） | 上行「群公告」，下面是公告正文预览（如「【群名称】…」），最右有 `>` |

**位置会漂移**：改名后群名长度变化、公告预览行数变化、会话列表滚动，都会让面板里各行整体上下移动几十像素。**每次操作前重新截图定位**，不要复用上一次的坐标。

## 群公告窗口（任务 2）

尺寸比其他窗口小（截图约 1100×1280，比例 1:0.5 半屏宽、满高）。

- **查看态**：标题「"群名"的群公告」，左上角是发布人昵称 + 发布时间（形如 `2026.10.02 12:29`），右上角一个「**编辑群公告**」按钮（x ≈ 0.86，y ≈ 0.11）
- **编辑态**：顶部出现排版工具条（对齐 / 无序列表 / 有序列表），右上角变绿色「**完成**」按钮（x ≈ 0.93，y ≈ 0.10）
- 正文可滚动；长文核对尾部（版本脚注）时用 `scroll` 工具或把窗口拉大

## 几个确认弹窗（都会拦截后续操作）

| 弹窗文字 | 按钮 | 出现时机 / 处理 |
|---|---|---|
| 修改群聊名称? | 取消 / **修改**（绿） | 改群名后按回车触发；点「修改」= 生效，会通知全体成员 |
| 发布此公告会通知全部群成员 | 取消 / **发布**（绿） | 点「完成」后触发；点「发布」= 正式发布 + 通知全体成员 |
| 关闭将不会保留本次编辑的内容 | **关闭**（红字）/ 继续编辑 | 误触关闭时出现；点「继续编辑」保住刚粘贴的内容 |

弹窗里的按钮都靠**颜色**识别最稳：绿色 = 主操作（修改 / 发布），红色文字 = 破坏性操作（关闭 / 取消）。

## 会「惊动群里」的三种操作（动手前跟用户对齐）

1. **改群名** → 系统提示「你修改群名为『…』」，全体可见
2. **发布群公告** → 系统提示 + 通知全体成员（弹窗里会明说）
3. **在群里发消息** → 内容永久留在群里，且以群主身份发出

## 界面操作的小抄

- **打开某个会话**（最稳）：⌘F 聚焦搜索 → 粘贴群名/备注名 → `Return` 打开第一条结果。搜索词要匹配**当前**名字（刚改完名就用新名字搜）
- **读群名/人数**：主窗口标题 `群名 (人数)`
- **进入群设置**：标题右侧「···」
- **清空输入框**：⌘A 后 `BackSpace`
- **取消当前弹窗**：`Escape`
- **别在聊天输入框里乱按键**：回车会直接把输入框里的内容发出去
